projects

tt

Every coding-agent CLI in one place. It's a desktop app: you add a project folder, then spawn Claude Code, Codex, Cursor, Gemini, opencode or just a plain shell in any directory. They tile side by side, each with a live dot telling you whether it's working or idle, and a status you set yourself. I built it because I was running four agents across five terminal tabs and constantly losing track of which one was actually doing something.

TabTasker

Around 50 browser tools where nothing leaves your machine. No uploads, no sign-up, works offline. The centrepiece is an LLM chatbot that runs entirely in the browser, and around it a set of generative pipelines: Whisper for speech-to-text, DistilBART for summaries, SpeechT5 for the voice, image captioning, and one that turns a PDF into a narrated podcast. File sharing and video calls go peer to peer over WebRTC.

teshub

Connected-vehicle telemetry. It takes raw data off the vehicle and turns it into metrics worth looking at, on an AWS pipeline built for low latency and for keeping the data private from the start.

Rasyonel

A study-prep app for students heading into university. I co-founded it and led development, and it got to #1 paid app in Turkey on both the App Store and Google Play in late 2018.
