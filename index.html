tt

Every coding-agent CLI in one place. A desktop app (Tauri + xterm.js): add a project folder, then spawn Claude Code, Codex, Cursor, Gemini, opencode or a plain terminal in any directory — tiled side by side, each with a live activity dot and a workflow status you set. Sessions run inside tmux, so they survive closing the app. I built it because I was juggling four agents across five terminal tabs and losing track of which one was actually working.
